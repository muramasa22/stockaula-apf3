# SA-01 · Una salida debe descontarse una sola vez

**Responsable académico** Leonardo Josue Minaya Ormeño · prioridad alta.

El encargado confirma la entrega de seis unidades. Si se pierde la respuesta y el navegador repite la solicitud, el almacén podría contabilizar dos entregas. El formulario ya envía una clave por operación. La API debe reconocerla.

## Criterios de aceptación

- Con 20 unidades, la primera salida de 6 responde 201 y deja 14.
- Reenviar la misma clave y el mismo contenido devuelve 200, recupera el mismo movimiento y conserva 14.
- Reutilizar la clave cambiando la cantidad o el motivo devuelve 409.
- Dos solicitudes concurrentes con la misma clave generan un solo asiento.
- Un cliente anterior que omita la clave conserva la posibilidad de registrar movimientos.
